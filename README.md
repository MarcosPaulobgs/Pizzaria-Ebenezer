# 🍕 Pizzaria Ebenézer - Landing Page Conceitual

> ⚠️ **AVISO LEGAL (DISCLAIMER):** Este projeto foi desenvolvido exclusivamente para fins de estudo, prática de engenharia de software e composição de portfólio pessoal. Ele não possui fins comerciais ou lucrativos, e os links e preços exibidos são estritamente fictícios para fins de demonstração técnica. Todos os direitos de imagem e marca pertencem à Pizzaria Ebenézer real.

Uma Landing Page moderna, rápida e totalmente responsiva criada para simular a presença online da **Pizzaria Ebenézer**, focando na apresentação do cardápio, facilidade de pedidos e conversão de clientes.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** - Estruturação semântica de toda a página.
* **CSS3** - Estilização customizada, design responsivo e efeitos visuais.
* **JavaScript** - Interações dinâmicas (como o carrossel de fotos e o menu de perguntas frequentes).

---

## 🎨 Funcionalidades do Projeto

* 📱 **Design Responsivo:** Adaptado perfeitamente para celulares, tablets e computadores.
* 🗺️ **Seções Estruturadas:** Hero section atraente, apresentação de combos/preços e área de FAQ (Dúvidas frequentes).
* 🔄 **Carrossel de Imagens:** Navegação fluida para exibição das pizzas.
* 💬 **Foco em Conversão:** Botões de chamada para ação (CTA) integrados simulando o direcionamento para pedidos.

---

## 🔮 Próximos Passos (Evolução do Projeto)

Como parte do meu aprendizado em Engenharia de Software, pretendo implementar as seguintes melhorias:
- [ ] **Carrinho de Compras:** Permitir que o usuário selecione as pizzas e veja o total somado em tempo real usando JavaScript.
- [ ] **Integração Fake com WhatsApp:** Criar uma função que pegue os itens do carrinho e gere um link automático para enviar o pedido formatado por mensagem.
- [ ] **Dark Mode:** Adicionar uma opção de tema escuro para melhorar a acessibilidade visual noturna.
